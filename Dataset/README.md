# Dataset

The project uses the Sleep Health and Daily Performance Dataset.

**Source:** [Kaggle dataset page](https://www.kaggle.com/datasets/mohankrishnathalla/sleep-health-and-daily-performance-dataset)

The analysis file supplied in the conversation was named `sleep_health_dataset(2).csv`. The raw dataset is not included in this repository update. Download it from the source page and review its license and redistribution terms before adding it to GitHub.

When permitted, place the CSV in this folder using a consistent name such as `sleep_health_dataset.csv`.

Do not upload private, sensitive, or restricted data.
